## 4. Notes de Release prêtes à copier (`v1.0.0`)

```markdown
## FRANÇAIS PRO v1.0.0 — Première version stable

**Écrivez mieux. Parlez juste. Progressez chaque jour.**

Projet réalisé de bout en bout par mes soins : conception produit, Design System Material 3, moteur linguistique français 100 % hors ligne, persistance Room, tests automatisés et livraison Android.

### Points clés de cette version
- **100 % hors ligne & privé** : aucune permission `INTERNET`, aucun compte, aucune publicité.
- **Correcteur linguistique hybride** : détection orthographe, grammaire, accords, conjugaison, homophones, ponctuation et style avec surlignage 4 couleurs et explications détaillées.
- **Parcours CECRL complet (A1 à C2)** : leçons structurées en 8 sections, 10 formats d'exercices, dictées audio (TTS local + repli visuel), dictionnaire, conjugueur + recherche inverse, vocabulaire SM-2, atelier de rédaction (10 modèles) et expression orale.
- **Statistiques & Sauvegarde** : 4 graphiques natifs alimentés par Room (19 entités) et export/import JSON via Android SAF.
- **Qualité vérifiée** : 18 tests unitaires & UI Robolectric validés, Android Lint sans erreur.

### Installation (Android 7.0+ / API 24+)
1. Téléchargez le fichier `.apk` ci-dessous.
2. Vérifiez son intégrité avec `SHA256SUMS.txt`.
3. Installez sur votre appareil Android et utilisez l'application immédiatement, même en mode avion.
```
